# On-Practice-VLA

On-Practice-VLA 是一个面向实践驱动迭代的研究项目。

本项目旨在构建具备基础知识先验的具身智能体，使其能够在实际交互中识别能力缺口，并通过交互反馈、事后复盘与误差纠偏，增量更新既有知识表征，将稳定有效的行为模式抽象为可复用技能，进而形成持续演化的学习闭环。

该闭环可概括为：

**实践 -> 复盘 -> 纠偏 -> 知识更新 -> 技能沉淀 -> 再实践**

项目重点：

- 基础知识先验
- 持续学习
- 在线学习
- 交互反馈与误差分析
- 增量知识更新
- 技能抽象与复用
- Agent 能力演化

与依赖大规模离线数据进行一次性训练，或通过反复重训模型实现能力更新的范式不同，本项目强调利用少量交互数据、在线反馈与技能抽象，实现模型能力的渐进式更新与长期演化。

## 版本迭代

| 版本 | 阶段 | 本版新增能力 | 训练 / 学习方式 | 输入 | 输出 | 预期效果 | 示例 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| v0.1.0 | CLIP 基线 | 保留 Simple-CLIP 的图文对齐能力 | 图文对比学习 | 图片 + 文本 | 图文相似度 | 实现图文匹配与检索，为视觉-语言策略学习提供表征基础 | 输入 `red block`，检索相关图片 |
| v0.2.0 | 动作预测头 | 在图文联合表征上增加离散动作预测头 | 动作分类 | 图片 + 指令 | 动作类别 | 建立视觉-语言表征到离散动作空间的映射 | “把红块拿起来” -> `pick` |
| v0.3.0 | 单步行为克隆 | 基于示范轨迹学习单步策略 | Behavior Cloning | 当前图片 + 指令 | 下一步动作 | 学习专家在给定状态下的动作决策 | 专家执行 `move_left`，模型预测 `move_left` |
| v0.4.0 | 短时序历史建模 | 引入近期状态与动作作为上下文 | 带历史信息的 BC | 图片 + 指令 + history | 下一步动作 | 利用时序上下文降低重复动作，并提升策略纠错能力 | 连续执行多次 `move_left` 后预测 `stop` |
| v0.5.0 | 动作参数化 | 将动作表示拆分为动作类型与参数 | 多头监督学习 | 图片 + 指令 + history | 动作类型 + 参数 | 提升动作空间的表达能力，避免枚举全部复合动作 | `move(direction=left, step=small)` |
| v0.6.0 | 动作块预测 | 一次预测多个连续动作 | 短序列监督学习 | 图片 + 指令 + history | action chunk | 建模短时序行为，提高动作执行的连续性与稳定性 | “靠近杯子” -> `move -> align -> stop` |
| v0.7.0 | 交互轨迹记录 | 记录观察、动作及任务结果 | 仅记录，不参与训练 | 执行过程 | interaction trace | 建立真实交互数据基础，为后续在线学习提供样本 | 记录 `pick` 失败及其原因“未完成对准” |
| v0.8.0 | 人机协同纠偏 | 引入人工修正动作或短轨迹 | 基于纠偏样本的增量微调 | 失败样本 + 人工修正 | 修正后的策略 | 利用少量人工反馈降低同类错误的重复发生率 | 将失败的 `pick` 修正为 `align -> pick` |
| v0.9.0 | 经验回放 | 混合新纠偏样本与历史示范数据 | Replay Buffer | demos + successes + corrections | 更新后的策略 | 缓解增量学习中的灾难性遗忘，保持既有任务能力 | 学习新桌面布局后保留原有红块任务能力 |
| v1.0.0 | 在线适应 | 基于交互反馈进行小步策略更新 | 小批量在线微调 | 新交互数据 + replay 数据 | 环境适应策略 | 提升策略对环境变化的适应能力，避免部署后模型固定 | 摄像头视角变化后通过数轮纠偏恢复性能 |
| v1.1.0 | 技能抽象 | 将高频动作序列抽象为可复用技能 | Skill-level BC | 图片 + 指令 + 可用技能 | skill 或 low-level action | 提升复杂任务的组合执行能力与经验复用效率 | `approach + align + pick` -> `pick_object` |
| v1.2.0 | 少样本迁移 | 通过少量示范或纠偏适应新任务 | Few-shot Adaptation | 少量新任务样本 + replay | 新任务策略 | 提升新任务的适应效率，降低任务迁移成本 | 基于少量示范执行“将杯子放置到盘子旁” |
| v1.3.0 | 持续评估 | 跟踪成功率、遗忘率与恢复速度 | 自动评估 + 模型回滚 | 多任务评估集 | 模型状态报告 | 量化持续学习效果，并在性能退化时支持版本回滚 | 新版本导致旧任务性能显著下降时自动回滚 |
