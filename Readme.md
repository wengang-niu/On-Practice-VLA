# On-Practice-VLA

On-Practice-VLA 是一个基于 simpleVLA 逐步改造的个人学习项目。目标不是一开始就做出完整的机器人自主学习系统，而是先把 simpleVLA 跑通，再沿着数据、表征、策略、闭环学习这条线一点点补齐能力。

项目名保持 `On-Practice-VLA`，强调的是“在实践中学习、在反复试验中修正”的路线。



## 目标

- 基于 simpleVLA 做逐步改造，而不是从零造一个大系统
- 用少量数据先跑出可见效果
- 让模型具备简单的闭环学习能力
- 逐步引入记忆、反馈和技能复用
- 最后形成“学会一个，再推广一个”的实践型路线
