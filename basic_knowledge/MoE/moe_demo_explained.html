MoE（混合专家）最小示例 · 算法讲解

对应源码 basic_knowledge/MoE/moe_demo.py · 一句话核心：多个专家子网络 + 一个路由器，输入来了由路由器决定交给哪个专家。

一、MoE 是什么

一个 MoE 模型由两部分组成：

  • 专家（Expert）：若干个并列的小网络，各自擅长某一种任务/区域。
  • 路由器 / 门控（Router / Gate）：看到输入 x 后，输出一组概率 pe(x)，决定「这个输入该交给哪个专家」。

本示例用 软路由：最终输出是所有专家输出的加权和，权重就是路由概率。

y(x) = p0(x)·expert0(x) + p1(x)·expert1(x) + p2(x)·expert2(x)，  其中 p(x) = softmax( gate(x) )

要点：专家们是「并列」的，谁都不天生知道该管哪段；是路由器学出了「把 x 分给谁」。所以 MoE 的能力既取决于专家，也取决于路由分得对不对。

二、这个 demo 要拟合什么

目标是定义在 [0, 1] 上的三段分段函数，每段都是一条直线，但行为完全不同：

第 0 段（升） x ∈ [0, 1/3) → y = 3x
第 1 段（平） x ∈ [1/3, 2/3) → y = 1
第 2 段（降） x ∈ [2/3, 1] → y = −3x + 3

三段区间互不重叠、谁也替代不了谁，所以必须分工——这正是 MoE 的理想场景。每段都是直线，任何小网络都能稳稳拟合，所以 demo 的重点是「路由分工」，而不是「拟合难曲线」。

三、训练两步（warm-start）

为了让分工干净、可复现、好可视化，这个 demo 用两步训练（而不是真实 MoE 的端到端联合训练）：

  1. 第 1 步 · 各训各的专家：用第 e 段的数据单独训练 experte，损失是回归的 MSE。训完每个专家就「只会自己那一段」。
  2. 第 2 步 · 冻结专家、只训路由器：把专家权重锁死（requires_grad=False），把路由器当 3 分类器训练（交叉熵），让门控学会「输入 x 属于哪一段 → 交给哪个专家」。

与真实 MoE 的区别：真实端到端 MoE 是专家 + 路由器一起训，路由器输出 softmax 软路由做加权组合，还要加「负载均衡」aux loss 防止所有样本涌向同一个专家。这里为了简单稳定，路由器用有监督方式训练，分工更干净。

四、代码逐段注解

4.1 目标函数 + 造数据

label 由两个阈值判断累加得到 0/1/2，正好对应三段；y 用 np.where 按段选直线。数据加了一点高斯噪声，变成真正的回归问题。

def target(x):
    """分段函数。返回 (y, 阶段标签)；标签只用于训练路由器/评估/画图。"""
    x = np.asarray(x, np.float64)
    label = (x >= 1 / 3).astype(int) + (x >= 2 / 3).astype(int)   # 0 / 1 / 2
    y = np.where(label == 0, 3 * x,
        np.where(label == 1, 1.0, -3 * x + 3))
    return y, label


def make_data(n=600, seed=0):
    rng = np.random.default_rng(seed)
    x = rng.uniform(0, 1, n)
    y, label = target(x)
    y = y + rng.normal(0, 0.02, n)   # 加一点噪声，变成真正的回归问题
    return x.astype(np.float32), y.astype(np.float32), label

4.2 专家 + 路由器

专家是一个小 MLP（1 → hidden → 1）；MoE 把 3 个专家和一个 gate 拼起来，forward 就是「各专家输出 × 路由概率求和」。

class Expert(nn.Module):
    """专家：小 MLP，1 维输入 → 1 维输出。"""
    def __init__(self, hidden=8):
        super().__init__()
        self.net = nn.Sequential(nn.Linear(1, hidden), nn.ReLU(), nn.Linear(hidden, 1))

    def forward(self, x):
        return self.net(x)


class MoE(nn.Module):
    """MoE = 若干专家 + 一个路由器（软路由：输出 = Σ p_e · expert_e(x)）。"""
    def __init__(self, num_experts=3, hidden=8):
        super().__init__()
        self.experts = nn.ModuleList([Expert(hidden) for _ in range(num_experts)])
        self.gate = nn.Sequential(nn.Linear(1, 8), nn.ReLU(), nn.Linear(8, num_experts))

    def forward(self, x):
        probs, out = self.route(x)
        return (out * probs).sum(dim=-1, keepdim=True)   # [B, 1]

    def route(self, x):
        probs = F.softmax(self.gate(x), dim=-1)               # [B, E]
        out = torch.cat([e(x) for e in self.experts], dim=-1) # [B, E]
        return probs, out

4.3 两个训练函数

fit_reg 是通用回归训练（MSE）；fit_router 只训练 gate，用交叉熵把「x → 该交给哪个专家」当成分类问题。

def fit_reg(model, xs, ys, epochs=300, lr=1e-2, batch_size=64, params=None):
    """回归训练（MSE）。params=None 训练全部参数；否则只训给定参数。"""
    x_t = torch.from_numpy(xs[:, None])
    y_t = torch.from_numpy(ys[:, None])
    opt = torch.optim.Adam(params if params is not None else model.parameters(), lr=lr)
    n = len(xs)
    for _ in range(epochs):
        perm = torch.randperm(n)                       # 每个 epoch 重新 shuffle
        for i in range(0, n, batch_size):
            idx = perm[i : i + batch_size]
            opt.zero_grad()
            loss = F.mse_loss(model(x_t[idx]), y_t[idx])
            loss.backward()
            opt.step()


def fit_router(moe, xs, labels, epochs=300, lr=1e-2, batch_size=64):
    """把路由器当 3 分类器训练（交叉熵），输入 x → 预测该交给哪个专家。"""
    x_t = torch.from_numpy(xs[:, None])
    y_t = torch.from_numpy(labels)                     # 阶段标签 0/1/2
    opt = torch.optim.Adam(moe.gate.parameters(), lr=lr)
    n = len(xs)
    for _ in range(epochs):
        perm = torch.randperm(n)
        for i in range(0, n, batch_size):
            idx = perm[i : i + batch_size]
            opt.zero_grad()
            loss = F.cross_entropy(moe.gate(x_t[idx]), y_t[idx])   # gate 输出 logits
            loss.backward()
            opt.step()

4.4 主流程（两步训练）

先对每个专家只喂自己那一段的数据做回归；再冻结专家，只训路由器；最后在测试集上算 MSE。画图部分对应下面交互区的两张图。

    # --- 第 1 步：每个专家只用自己那段数据训练（warm-start）---
    moe = MoE(3)
    for e in range(3):
        m = l_tr == e
        fit_reg(moe.experts[e], x_tr[m], y_tr[m])

    # --- 第 2 步：冻结专家，只训练路由器（3 分类）---
    for e in moe.experts:
        for p in e.parameters():
            p.requires_grad = False
    fit_router(moe, x_tr, l_tr)

    # --- 测试集表现 ---
    with torch.no_grad():
        pred = moe(torch.from_numpy(x_te[:, None])).numpy().ravel()
    print(f"测试集 MSE: {np.mean((pred - y_te) ** 2):.4f}")
